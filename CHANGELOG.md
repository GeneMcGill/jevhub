# Changelog

All notable changes to **JevHub** are documented here. Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioned with [SemVer 2.0.0](https://semver.org/).

## [0.1.0]

### Added
- **Astro 5 static catalog** of the Jev / System-1 ecosystem: 864+ projects, seeded from [awesome-jev-projects](https://github.com/logicrw/awesome-jev-projects).
- **whatships-style UI**: header hero, category chips (All / AI / Developer tools / Design / Motion / Productivity / Consumer / Hardware / Other), launch-card grid, per-project `/videos/<slug>/` detail pages.
- **Tools** — alphabetical index; **Studios** — teams ranked by stars.
- **Submit** — issue-only flow, no pull requests needed for catalog changes.
- **Zero-paid-API data pipeline** — collectors via GitHub REST Search API + HN Algolia, refreshed daily.
- **`llms.txt` + JSON-LD** (`Dataset`, `SoftwareApplication`) for AI citation readiness.
- License: MIT.

### Fixed
- README language navigation; English default with 简体中文 on a separate `README.zh-CN.md`.
